## 3. 域名访问真相 — `thudance.top` vs `www.thudance.top`

### 3.1 DNS 解析链

```
thudance.top        CNAME → d09c4fc...qcloudcjgj.com
                    CNAME → 1e56d013...qcloudwzgj.com
                    A     → 175.178.32.68          （腾讯云 CDN/WAF 边缘节点）

www.thudance.top    A     → 43.143.228.61          （直连源站 nginx）
```

### 3.2 实测响应

| URL | 结果 | 特征 |
|---|---|---|
| `https://thudance.top/` | 200，内容 455 字节 `index.html` | Header 带 `X-WAF-UUID:…`（腾讯云 WAF） |
| `http://thudance.top/` | **200，未跳转 HTTPS** | Header 带 `X-Waf-Uuid`，`Keep-Alive: timeout=4`（CDN 特征） |
| `https://www.thudance.top/` | **TLS 握手失败** `SSL_ERROR_SYSCALL` | 服务器 443 端口未开，无证书 |
| `http://www.thudance.top/` | 200，同样内容 | `Server: nginx/1.24.0 (Ubuntu)`（直接暴露源站） |
| `http://43.143.228.61/` | 200，同样内容 | 裸 IP 直连，**完全绕过 WAF** |

### 3.3 解答 Luna 的问题

**Q: 为什么 `http://www.thudance.top` 和 `https://thudance.top` 都能访问？**

它们走的是**两条完全不同的路径**，但最终命中同一台 nginx / 同一份前端 dist：

1. `https://thudance.top` — 访问者 → 腾讯云 CDN/WAF (175.178.32.68)（**CDN 侧持证书**，HTTPS 在此终结）→ 回源 HTTP 到 43.143.228.61:80 → nginx → dist
2. `http://www.thudance.top` — DNS 把 www A 记录直接指向 43.143.228.61 → nginx 80 → dist

所以两条都通；**但只有第一条受 WAF 保护、有 HTTPS、有 CDN 缓存**。

**Q: 二者区别？**

| 维度 | `https://thudance.top`（CDN 路径） | `http://www.thudance.top`（直连路径） |
|---|---|---|
| TLS | ✅ 腾讯云终结 | ❌ 明文 |
| WAF | ✅ 基础 Web 防护 | ❌ 裸奔 |
| CDN 缓存 | ✅ 静态资源边缘缓存 | ❌ 每次回源 |
| 真实源 IP 曝露 | 隐藏 | **直接曝露** 43.143.228.61 |
| Cookie/JWT 传输 | 加密 | **明文可截获**——最致命 |
| DDOS / CC 缓冲 | 有 CDN 扛 | 直接打到源站 |

**Q: 能不能把 HTTP 那个关掉？**

**应该关，且关掉有三层动作：**

#### 方案 A（推荐，最彻底）: 让 www 也走 CDN，关闭 80 直连
1. **腾讯云 DNS 控制台**
   - 将 `www.thudance.top` 的 A 记录 **改成 CNAME** 指向 `thudance.top`（或 CDN 给出的同一个 `*.qcloudcjgj.com`）
   - 这样 www 也走 CDN/WAF，有 HTTPS
2. **腾讯云 CDN/WAF 控制台**
   - 给 CDN 域名绑定 `www.thudance.top`，加证书（和裸域同证书或申请通配符/SAN）
   - 启用 **强制 HTTPS**（HTTP 301 → HTTPS）
   - 可选：启用 HSTS（`max-age=31536000; includeSubDomains; preload`）
3. **服务器 nginx**
   - 将 `listen 80` 站点 **关闭对域名 Host 的响应**，只保留对腾讯云 CDN 回源 IP 的响应；或用 `allow`/`deny` 限制只允许 CDN 源 IP 段回源
   - 或更干脆: 给 nginx 加一个 `return 444;` 的默认 server 拦所有非 CDN 回源的请求
4. **腾讯云轻量安全组 + UFW**
   - 80 端口仅允许腾讯云 CDN 回源 IP 段；22 改成密钥 + 限制来源 IP
   - 5000 端口从 UFW 删除（服务根本不在）

#### 方案 B（快但不彻底）: 只在源站强制 301
在 nginx `dt-cw` 站点加：
```nginx
if ($host = "www.thudance.top") {
    return 301 https://thudance.top$request_uri;
}
```
缺点：www 走的路径依然没有 HTTPS，浏览器先发一个 HTTP 请求，Cookie 仍可被嗅探；且 301 后跳到裸域会丢掉 www 的 SEO 权重。

#### 方案 C（最简单）: 直接把 www 的 A 记录删掉
弊端：以前收藏 `www.thudance.top` 的用户直接无法访问。

**我的建议**: 方案 A。如果你想快速止血，今天先做**方案 B + 把 `http://thudance.top` 在腾讯云 CDN 侧启用"强制 HTTPS"**，本周内完成方案 A。
